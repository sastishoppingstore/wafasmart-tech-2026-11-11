What this tool does

This page measures the connection your browser is using right now. It opens several parallel streams against Cloudflare's public test servers, counts the bytes that actually land, and divides by real elapsed milliseconds. Nothing on the dial is estimated or pre-written.

Four stages run in order: ping and jitter from ten tiny round trips, then download across three to six streams sampled four times a second, then upload read from the browser's own upload-progress events, then a plain-English verdict on what the number is good enough for.

The test starts on its own a third of a second after the page opens. If your browser has data-saver switched on it waits for your press instead, because a full run moves real megabytes. Pick Quick, Standard or Precise to set that budget.

Below the meter you get the IP address the test server answered, plus the city, area, country and provider resolved from it — the same way every online speed test labels your line.

Every figure is computed on your device. Nothing is stored, no result is posted anywhere, and the browser's own location permission is never touched.

How to use the Internet Speed Test | Step by Step Guide

  1. Open the page — the test starts on its own after a moment.
  2. Watch the coloured meter during the download stage; the needle is showing live throughput, not a final guess.
  3. Read the five result boxes: download, upload, ping, best ms and jitter.
  4. Check the connection panel below for your IP, provider, city and area, and where the marker sits on the grid.
  5. Press Test again for a second sample, or Stop to end a run early — Wi-Fi swings, so keep the better number.

Tips

  • Close streaming, downloads and cloud sync first — they are the usual reason a result looks half what you pay for.
  • Test on the same band you use: 2.4 GHz Wi-Fi through a wall is not your fibre line's real speed.
  • A VPN reroutes you through another server and inflates ping; turn it off to measure the bare connection.
  • Mobile data results swing by 50% between one minute and the next — take three samples.
  • If the dial sits at zero with a red error, your network is blocking the test endpoints (common on school and office proxies) — the page then falls back to jsDelivr test files for download and says so under the results.
  • If the city looks wrong, your ISP routes traffic through another hub — IP geolocation names the exit city, not your room.

Frequently asked questions

Is the speed test free to use?

Yes — speed test has no usage cap, no sign-up and no watermark, and it is not a trial: the page is a static file on https://wafasmart.tech with no billing backend behind it. There is no “premium” dial — the same measurement runs for everybody.

Why does the page show my IP address and city?

The IP is taken from the reply header of the test server, which already sees it for every request you make to any website; the city, area and provider come from one public IP-geolocation lookup of that address, the same labelling every online speed test uses. Nothing is written down, sent to this site, or cross-matched with anything else — turn the panel off in your browser by blocking that one lookup request if you would rather it stayed blank.

Does the speed test upload any of my files?

No. Upload testing sends a block of random bytes generated in memory, never a file from your device, and the receiving endpoint is Cloudflare's public test collector.

Why is my download number lower than my advertised plan?

Wi-Fi contention, one busy background app, a VPN, or a single-stream server can each cost you 20–60%. This test uses several parallel streams, which is closer to your line's real ceiling than a single-stream test.

What is jitter and why should I care?

Jitter is the variation between successive pings. A 30 ms ping with 2 ms jitter feels smoother on a call than a 15 ms ping with 40 ms jitter — games and video calls care about jitter more than raw latency.

Why did the test not start by itself?

Either your browser's data-saver mode is on (the page deliberately waits for a click then), or the network blocked the first request. Press the button to retry.

Can I trust these numbers over speedtest.net?

They are measured the same way — parallel streams, byte counting, wall-clock timing — against a different server set, so small differences are normal. Two consecutive runs from one tool tell you more than one run from any tool.

Can I use it on my phone?

Yes. Internet Speed Test is mobile-first: one column, big tap targets, and the system keyboard opens with sensible number/text input. On iPhone, Files and the share sheet feed the picker the same way Downloads does on Android. The meter is drawn in SVG, so it fills a phone screen cleanly and works on mobile data.
